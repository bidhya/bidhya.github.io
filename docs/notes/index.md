# Engineering Notes

Evergreen technical references, organised by domain. These are written to be returned to:
each one covers the reasoning behind a technique, the trade-offs that decide when to reach
for it, and the failure modes that show up at production scale.

Many articles sit in more than one domain — machine learning applied to satellite imagery,
or deep learning that only runs at all on a cluster. The navigation files each article in
one place; the [tag index](../tags.md) shows the cross-links.
